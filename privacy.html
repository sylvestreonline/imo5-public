Politique de confidentialité

Dernière mise à jour : 16 octobre 2026

CYBERBOY SARL (« nous », « IMO5 »), éditeur de l'application IMO5, s'engage à protéger la vie privée de ses utilisateurs. Cette politique explique quelles données nous collectons, pourquoi, comment nous les protégeons, et vos droits.

1. Données collectées

Nous collectons les données suivantes lorsque vous utilisez IMO5 :

  • Numéro de téléphone (identifiant principal, collecté à l'inscription via vérification OTP)
  • Nom d'affichage et photo de profil (optionnelle)
  • Email (optionnel, pour les notifications)
  • Photos et informations des annonces publiées
  • Messages échangés entre utilisateurs via la messagerie IMO5 (uniquement visibles par les 2 participants)
  • Documents de vérification propriétaire (CNI, facture SEEG, titre foncier) — chiffrés, accessibles uniquement aux modérateurs IMO5
  • Références de paiement mobile money (numéro payeur + ID transaction) pour les Boosts
  • Données techniques : type d'appareil, version système, logs d'activité (via Firebase Analytics)
  • Token de notification push (FCM) pour vous envoyer des notifications

2. Finalités du traitement

Nous utilisons vos données uniquement pour :

  • Vous authentifier et créer votre compte
  • Afficher vos annonces publiques et faciliter la mise en relation avec d'autres utilisateurs
  • Modérer le contenu publié (vérification des documents propriétaire, traitement des signalements)
  • Envoyer des notifications liées à votre activité (nouveau message, changement de statut d'annonce, validation KYC)
  • Prévenir les abus, les fraudes et la coordination de faux signalements
  • Améliorer le produit via des statistiques agrégées et anonymes

3. Partage avec des tiers

Vos données ne sont jamais vendues. Elles ne sont partagées que dans les cas suivants :

  • Avec un autre utilisateur IMO5 : uniquement les informations publiques de votre profil (nom, photo, statut vérifié, numéro si vous le partagez volontairement dans un message)
  • Avec un partenaire IMO5 (banque pour un prêt, assureur pour une habitation) : UNIQUEMENT après votre consentement explicite via le formulaire « Services partenaires », et UNIQUEMENT les coordonnées que vous avez volontairement renseignées
  • Avec Firebase (Google LLC) : hébergement des données (serveurs Firestore, Storage, Cloud Functions). Google agit en tant que sous-traitant technique.
  • En cas d'obligation légale (demande judiciaire, autorité compétente gabonaise)

4. Sécurité

Toutes les communications entre l'application et nos serveurs sont chiffrées en transit (HTTPS/TLS). Les données sensibles (documents KYC) sont stockées chiffrées au repos.

L'accès aux données personnelles est strictement limité : seuls les modérateurs IMO5 agréés peuvent consulter les documents de vérification, dans le cadre strict de leur mission.

5. Durée de conservation

  • Compte actif : tant que votre compte est actif
  • Historique des transactions : 90 jours puis suppression automatique
  • Documents KYC : conservés tant que votre vérification est valide, supprimés sous 30 jours après suppression de votre compte
  • Messages privés : tant que la conversation est active (vous pouvez la supprimer à tout moment)
  • Annonces supprimées : conservées 7 jours puis purgées

6. Vos droits

Vous disposez des droits suivants sur vos données :

  • Accès : voir les données que nous avons sur vous
  • Rectification : corriger les données inexactes (depuis « Modifier mon profil »)
  • Suppression : demander la suppression de votre compte et de vos données associées
  • Opposition : refuser le traitement de certaines données (ex. partage avec partenaires)
  • Portabilité : récupérer vos données dans un format exploitable

Pour exercer ces droits, écrivez à sylvestreonline@gmail.com. Nous répondons sous 30 jours maximum.

7. Cookies et traceurs

IMO5 n'utilise pas de cookies tiers publicitaires. Firebase Analytics est utilisé pour mesurer l'utilisation anonyme de l'application (nombre d'écrans ouverts, actions principales). Aucune donnée personnelle n'est transmise à des régies publicitaires.

8. Mineurs

IMO5 est strictement réservé aux personnes âgées de 18 ans ou plus. Nous ne collectons pas sciemment de données de mineurs. Si vous estimez qu'un mineur a créé un compte, écrivez-nous à sylvestreonline@gmail.com pour suppression immédiate.

9. Modifications de la politique

Cette politique peut évoluer. Les modifications substantielles seront notifiées via l'application au moins 15 jours avant leur entrée en vigueur.
